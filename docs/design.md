Дизайн застосунку PulseForge
Світла тема. Стиль спирається на мокап: логотип акцентного кольору, світлий фон вікна, білі картки й поля, закруглені кути.

Шрифти
ScienceGothic: логотип і заголовки форм (26 px). Якщо в шрифті немає кирилиці, WPF автоматично бере Segoe UI для відсутніх символів.
Segoe UI: весь інший текст.

Відступи й розміри
Базова одиниця: 8 px
Відступ від краю вікна: 24 px
Відстань між кнопками й групами полів: 16 px
Відстань між підписом і полем: 4 px
Висота кнопки: не менше 40 px, поля вводу: не менше 36 px
Радіус закруглення кутів кнопок і полів: 6 px
Спільні стилі (ресурси WPF)
Усі стилі лежать у `Resources/Styles.xaml` і підключаються в `App.xaml`.
Ключ стилю	Для чого
`AppWindow`	вікно: фон, шрифт, колір тексту
`FormTitle`	заголовок форми
`FieldLabel`	підпис поля
`FieldInput`	поле вводу (TextBox, ComboBox)
`FieldError`	текст помилки
`PrimaryButton`	основна кнопка (заповнена акцентом)
`SecondaryButton`	другорядна кнопка (біла, з рамкою)
`StatusText`	текст статусу
Макети вікон
Головне вікно (MainWindow)
Заголовок «PulseForge», під ним три основні кнопки на всю ширину.
```
┌──────────────────────────────┐
│ PulseForge                   │
│ ┌──────────────────────────┐ │
│ │        Реєстрація        │ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │     Нове тренування      │ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │    Шаблон тренування     │ │
│ └──────────────────────────┘ │
└──────────────────────────────┘
```
Вікно «Реєстрація»
Заголовок форми, поля (підпис + поле вводу), текст помилки під полем, кнопки «Зареєструватися» (основна) і «Скасувати» (другорядна).
Вікно «Нове тренування»
Заголовок форми, поля вводу, текст помилки, кнопки «Зберегти» (основна) і «Скасувати» (другорядна).
Вікно «Шаблон тренування»
Заголовок форми, поле «Назва», вибір вправи з каталогу, поля «Підходи» і «Повторення», список вправ шаблону, текст помилки, кнопки «Зберегти» (основна) і «Скасувати» (другорядна).
